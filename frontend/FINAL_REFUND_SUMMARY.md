## 🔍 أمثلة الحسابات الفعلية

### مثال 1: 100% Refund
```javascript
الحجز: $1000 | الدفع: Full | الأيام: 50
→ السياسة: 100% ✅
→ المسترجع: $1000
→ الرسوم: $0 (لا رسوم للـ 100%)
→ الصافي: $1000
```

### مثال 2: 50% Refund مع رسوم
```javascript
الحجز: $500 | الدفع: Deposit | الأيام: 20
→ السياسة: 50% ⚠️
→ الدفعة: $150 (30%)
→ المسترجع: ($150 × 50%) = $75
→ الرسوم: $75 × 5% = $3.75
→ الصافي: $71.25
```

### مثال 3: Non-Refundable
```javascript
الحجز: $300 | الدفع: Full | الأيام: 3
→ السياسة: 0% ❌
→ المسترجع: $0
→ الإجراء: قد يكون قابل للإعادة
```
