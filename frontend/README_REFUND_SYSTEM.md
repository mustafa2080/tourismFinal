تم تطوير **نظام احترافي وكامل** لإدارة المسترجعات يعمل بسلاسة بين Backend و Frontend.

## 🎯 كيفية الاستخدام الفوري

### في صفحة Admin Dashboard:

```jsx
import useRefund from '@/hooks/useRefund';

function RefundsPage() {
  const {
    refunds,         // قائمة المسترجعات
    stats,          // الإحصائيات
    loading,        // حالة التحميل
    approveRefund,  // دالة الموافقة
    rejectRefund    // دالة الرفض
  } = useRefund();

  // كل شيء يعمل من الصفحة الموجودة بالفعل! 🚀
}
```

### النظام يقوم تلقائياً بـ:

1. ✅ **حساب السياسة** - بناءً على تاريخ الرحلة
2. ✅ **حساب المبلغ** - حسب نوع الدفع
3. ✅ **الموافقة/الرفض** - مع تحديثات فورية
4. ✅ **إرسال البريد** - رسالة تلقائية للعميل
5. ✅ **تحديث الإحصائيات** - فوراً

## 💰 سياسات الاسترجاع

```
الأيام المتبقية  │  النسبة  │  الحالة
─────────────────┼─────────┼──────────
≥ 30 يوم       │ 100%    │ ✅ Full
15-29 يوم     │ 50%     │ ⚠️ Partial
7-14 يوم      │ 25%     │ ⚠️ Limited
< 7 أيام      │ 0%      │ ❌ None
```

---

## 💳 أنواع الدفع

### 1. Pay on Arrival (💵)
- المبلغ المسترجع: **$0** (لم يدفع بعد)
- الإجراء: منع جمع الدفعة

### 2. Deposit (📦)
- دفعة مقدمة: **30%** من السعر
- الاسترجاع: حسب السياسة - 5% رسوم

### 3. Full Payment (💳)
- المبلغ: **100%** من السعر
- الاسترجاع: حسب السياسة - 3% رسوم

## 🎓 أمثلة عملية

### مثال 1: 100% Refund
```javascript
الحجز: $1000 | الرحلة: 50 يوم
→ نسبة: 100% ✅
→ المسترجع: $1000
→ الرسوم: $0
→ الصافي: $1000
```

### مثال 2: 50% Refund
```javascript
الحجز: $500 | الرحلة: 20 يوم
→ نسبة: 50% ⚠️
→ المسترجع: $250
→ الرسوم: $12.50 (5%)
→ الصافي: $237.50
```

### مثال 3: Non-Refundable
```javascript
الحجز: $300 | الرحلة: 3 أيام
→ نسبة: 0% ❌
→ المسترجع: $0
→ الإجراء: قد يكون قابل للإعادة
```
